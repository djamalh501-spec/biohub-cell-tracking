# Biohub Cell Tracking

Cell tracking and division-aware lineage reconstruction pipeline developed for the Biohub microscopy tracking challenge.

## Overview

This project focuses on detecting and tracking cells across microscopy sequences, reconstructing lineage relationships, and evaluating division events under competition constraints.

## Engineering work

- Cell detection and tracking
- Division-aware graph reconstruction
- GEFF/Zarr data handling
- Official metric integration
- Baseline reproduction and benchmarking
- GPU/CPU inference workflows
- Checkpoint and provenance verification
- Reproducible evaluation pipelines
- Automated tests and audit reports

## Tech stack

Python · PyTorch · NumPy · Zarr · Computer Vision · Scientific ML · Kaggle

## Repository structure

- `src/` — core tracking and evaluation code
- `notebooks/` — experiments and validation work
- `tests/` — automated tests
- `*.md` reports — evaluation, schema, graph and oracle audit notes

## Notes

Competition datasets and large external assets are not included in this repository.
